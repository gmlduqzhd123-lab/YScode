# 전체 앱 「📲 앱 설치 · 📱 QR」 상단 배치 점검

목표: 모든 앱에서 두 버튼이 **첫 화면 맨 윗줄에 나란히**, 휴대폰(360·390px)과 PC(1280px) 모두에서 **가로로 넘치거나 잘리지 않게** 보이는지 확인한다. 엽쌤이 정한 기준은 "휴대폰에서도 맨 윗줄"이다(둘째 줄은 고칠 대상).

## 순서

1. 도구 준비 후 최신 코드로 띄우기
   ```bash
   cd <스킬 폴더>
   source scripts/setup-tools.sh
   bash scripts/prepare-local.sh > /tmp/ys-prep.log 2>&1   # 모든 앱을 origin/main 으로 맞추고 빌드, 8810(정적)·3100(엽쌤스쿨) 실행
   # 빌드가 이미 최신이면 --no-build, 일부만이면 --only Hwp,padlet
   ```
   출력은 **파일로 돌려라**(`| tail` 같은 파이프 금지). 뒤에 켜 둔 서버가 파이프를 붙잡아 명령이 끝나지 않고 시간 초과로 죽은 적이 있다. 측정기도 오래 걸리니(앱 23개 × 3폭 ≈ 5~10분) `run_in_background`로 돌리고 결과를 파일(`> /tmp/ys-topcheck.txt`)로 받는다.
   작업 중인 변경이 있는 저장소는 동기화를 건너뛰고 알려 준다 — 그 경우 먼저 정리할지 판단한다.
2. 측정
   ```bash
   node scripts/topcheck.cjs              # 표 출력 + /tmp/ys-shots/ 에 앱별·폭별 스크린샷
   ```
   표의 뜻: `✅ 맨 윗줄` / `⚠️ 둘째 줄`(두 버튼은 같은 줄이지만 첫 줄이 아님) / `⚠️ 줄 나뉨`(두 버튼이 다른 줄) / `❌ … 없음` / `·가로넘침` `·잘림` `·오류`. QR 창 열(390px에서 눌러 봄).
3. **⚠️·❌는 반드시 스크린샷을 직접 열어 본다.** 측정기는 위치만 재므로 오판이 있을 수 있다:
   - 역사 탐험 퀘스트: 서비스 워커가 막히면 "오프라인 준비 실패" 안내가 맨 위에 떠서 버튼이 아래로 밀려 보인다 → 측정기는 서비스 워커를 허용하므로 보통 문제없음. 그래도 밀려 보이면 이 안내 때문인지 확인.
   - For-Teacher: Tailwind CDN이 막히면 화면이 깨진다 → 측정기가 로컬 사본으로 대체(`YS_TAILWIND`). 아이콘 글꼴(Font Awesome)은 안 보여도 정상.
   - 아카펠라: 첫 방문 사용법 창 → 측정기가 닫고 잰다.
   - 한려초 수영부: 로그인 화면 뒤 헤더라 측정 불가 → `src/app/dashboard/layout.tsx`의 모바일·PC 헤더에 `data-ys-install`, `data-qr` 버튼이 있는지 코드로 확인하고, 그 사실을 보고에 적는다.
   - 엽쌤스쿨: 메뉴(☰)가 화면 밖으로 밀린 적이 있다 → 헤더의 가장 오른쪽 요소가 화면 폭 안인지도 본다(스크린샷).
4. 결과 보고(고치기 전). 아래처럼 묶어서 짧게:
   - 휴대폰·PC 모두 맨 윗줄 (N개): 앱 이름 나열
   - PC는 맨 윗줄, 휴대폰은 둘째 줄 (N개): 앱마다 "첫 줄에 무엇, 둘째 줄에 무엇"
   - 문제(넘침·잘림·버튼 없음)
   - 측정 못 한 앱과 이유, 접근 권한 없는 앱
   - "공개 사이트는 이 환경에서 열 수 없어 최신 코드를 같은 경로로 띄워 확인" 한 줄
   - 고칠 게 있으면 "맨 윗줄로 올릴까요?"로 묻는다. 사용자가 처음부터 "올려줘/고쳐줘"라고 했으면 바로 고친다.
5. 고칠 때는 `layout-fixes.md`의 방법을 쓰고, 고친 앱만 `--only`로 다시 측정한다(320px도 한 번 보고, 360px 이상에서 맨 윗줄이면 합격 — 320px에서 둘째 줄로 내려가는 것은 보고만). 저장소에 테스트가 있으면 돌린다. 마무리는 `git-workflow.md`.
6. 끝나면 서버 정리: `for p in $(pgrep -f "[h]ttp.server 8810") $(pgrep -f "[n]ext start -p 3100"); do kill $p; done`

## 앱별 메모 (지금까지 확인된 배치)

- 모음집: 헤더 오른쪽 「앱 설치」「QR」, 480px 이하에서 「엽쌤 소개」는 얼굴만.
- 4시 40분의 용사(old-game): 휴대폰 1줄 = 오락실 이름 + 설치·QR, 2줄 = 음악·목록 (`.ix-nav-key` / `.ix-nav-more`, `display:contents`).
- 아시안게임: 1줄 = 앱 이름 + 설치·QR, 2줄 = 목록 (`.ld-key`).
- 우리 함께 아카펠라: 1줄 = 제목 + 설치·QR, 2줄 = 배지·사용법·스튜디오 (`.header-key` + `.header-break`). 스튜디오: 1줄 = 제목 + 설치·QR.
- 역사 탐험 퀘스트: 1줄 = 앱 이름 + 「📲 설치」「📱 QR」.
- Math Survival: 휴대폰은 시작 카드 맨 윗줄 오른쪽(제목은 아래), PC는 제목 줄 오른쪽.
- 명운: 맨 윗줄 오른쪽(도장·제목은 아래).
- 아카라카: 상단 버튼 순서 앱설치 → QR → 설명서 → 첫 음 잡기 → 곡 추가.
- 패들렛 정리함: 1줄 = 제목 + 설치·QR, 2줄 = 「로컬 가져오기」.
- 한글 마감실: 1줄 = 「한 한글 마감실」 + 설치·QR, 2줄 = 메뉴·시험판 표시.
- 지도안 대백과: 헤더 오른쪽(휴대폰은 ☰ 옆).
- 웜즈: 게임 시작 화면 패널 맨 윗줄 오른쪽.
